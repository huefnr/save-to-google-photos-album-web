# Save to Google Photos Album — Website

Product, pricing, policies, and support for the **Save to Google Photos Album** Chrome extension, published with GitHub Pages.

The public pricing is Basic plan (free) and planned Plus plan (USD $19.99/year), with a
14-day trial once per eligible Google account. Plus plan is not yet open for purchase.
Before opening checkout, configure the matching trial in Paddle and enforce
one-trial eligibility on the backend; website copy does not enforce eligibility.
Local pricing and tax treatment vary by customer location, and the final price
is shown at checkout.

- Home: https://save-to-album.com/
- FAQ: https://save-to-album.com/faq/
- Privacy: https://save-to-album.com/privacy/
- Terms: https://save-to-album.com/terms/
- Refunds: https://save-to-album.com/refunds/
- Support: https://save-to-album.com/support/
- Checkout: https://save-to-album.com/checkout/

## Copy Release Gates

Run `node scripts/test-launch-copy.mjs` and the policy browser test
`node scripts/test-policy-pages.mjs` before publishing copy edits. Read
`LAUNCH_CHECKLIST.md` before public launch; `PUBLIC_LAUNCH=1 node
scripts/test-launch-copy.mjs` must pass before enabling public purchases.
